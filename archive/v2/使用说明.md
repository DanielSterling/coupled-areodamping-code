# 停机塔顶四自由度气动阻尼

本版本根据2026-10-16上传的主程序改写，直接构造塔顶4x4气动阻尼。

## 自由度与物理范围

- 全局X=SS、Y=FA、Z向上；所有矩阵关于同一塔顶参考点。
- 位移顺序：q4=[uX;uY;thetaX;thetaY]。
- 载荷顺序：Q4=[FX;FY;MX;MY]。
- delta_Q4=-C4*q4dot；动力学方程左侧使用+C4*q4dot。
- 保留全部16项，不套用运行风轮的零元素分布，不强制对称化。
- 四个塔顶物理气动通道不等于四阶模态，不等于四个状态变量。

本版本直接计算B4与C4，不先生成C6再截取。在相同几何、截面C2和积分下，数学上C4等于原C6的[1,2,4,5]主子矩阵。验证程序用这一关系作交叉检查。

省略的是塔顶uZ、thetaZ速度的气动反馈，以及FZ、MZ气动载荷。它不是对完整六自由度系统的精确动力凝聚。结构仍为每节点6自由度；若继续时程，结构中的uZ、thetaZ没有被约束为零，其气动反馈被忽略。倾角、锥角和偏置存在时，完整模型被省略的通道可能非零，需要通过原模型评估近似误差。

## 文件与运行

1. 解压后，把现有my260数据文件夹放在main_parked_tower_aero_4dof.m旁边。数据文件不包含在本代码包中。
2. MATLAB运行main_parked_tower_aero_4dof.m。
3. 默认enableTimeResponse=false，计算、显示并保存4x4矩阵后结束。
4. 如需沿用附件的扰动力响应，将enableTimeResponse改为true。

functions目录包含所需通用函数与一个新函数build_parked_rotor_aero_damping_4dof.m；新函数内部完成三叶片攻角、截面矩阵、速度映射、积分及求和。无需覆盖原工程，建议在本目录运行。

数据沿用原格式：tatong.xlsx、nacelle.xlsx、hub.xlsx、blade_rna.xlsx、blade_geo.xlsx、AerofoilDatabase.xlsx、AerofoilSectionSet.xlsx。

## 默认工况

与本次上传主程序一致：停机0 rpm，风速20 m/s，空气速度方向240度，空气密度1.29 kg/m^3，叶片方位[0,120,240]度，桨距[90,90,90]度，3点Gauss，结构阻尼0。主程序求解16阶无阻尼模态；若开启时程，保留6阶耦合模态，时长400 s，步长0.02 s，FA扰动力幅值参数20 kN、4周期。倾角、锥角和叶根偏置从RNA输入读取。

独立变桨只修改主程序的bladePitchSet_rad，例如deg2rad([78;90;85])。叶片坐标和气动攻角共用这组桨距。

## 核心计算

对塔顶到截面的力臂r=[rx;ry;rz]：

```matlab
G4 = [1 0 0 rz; 0 1 -rz 0; 0 0 ry -rx];
B4 = R_reference(:,1:2).' * G4;
C4 = C4 + B4.' * Ca2 * B4 * integrationWeight;
```

G4第三行必须保留：即使不取塔顶竖向平移，塔顶转动仍能产生截面竖向速度，倾角和锥角可能使这部分速度投影到截面XY平面。

端点截面C2和位置均线性插值；每个高斯点重新计算力臂及B4。积分权重含段长/2。三叶片分别查询当前攻角的系数及导数，不将单叶片结果直接乘3。

结构装配：P4取塔顶[uX,uY,thetaX,thetaY]，C_global=P4.'*C4*P4。模态投影使用原结构完整振型，保持非对称和非对角耦合。四个气动通道与保留模态数可独立设置。

## 输出

results/parked_aero_4dof/下保存：

- three_blade_aero_damping_4dof.mat：C4总矩阵、逐叶片矩阵、截面诊断与结构数据。
- rotor_tower_top_aero_damping_4dof.csv：含物理行列名称的4x4总矩阵。
- 开启时程后另有模态模型MAT、位移TXT、载荷TXT、响应MAT和响应图。

主要变量：

| 变量 | 大小 | 含义 |
| --- | --- | --- |
| dampingMatrixRotor4_atTowerTop | 4x4 | 风轮总塔顶阻尼 |
| dampingMatrixBlade4_atTowerTop | 4x4x3 | 三支叶片分别贡献 |
| rotorAero4Out.bladeAeroOut(b).sectionDampingMatrix2 | 2x2xn | 截面单位长度阻尼 |
| rotorAero4Out.bladeAeroOut(b).gaussPointInfo.sectionVelocityMap4 | 2x4xnGauss | 截面速度映射 |
| C_aero_tower_free | nf x nf | 装配后的结构自由子矩阵 |
| C_aero_modal | nMode x nMode | 开启时程后得到的完整模态阻尼 |

C4左上2x2单位N*s/m；交叉块N*s；右下2x2单位N*m*s，rad按无量纲处理。它不是阻尼比。

## 验证与边界

verification/verify_parked_aero_4dof.m可在MATLAB运行，不依赖Excel，使用人工几何与光滑极曲线检查三叶片求和、与六通道主子矩阵关系、叉乘速度、功率、非线性载荷速度差分、2/3点Gauss及零风速。人工结果不是my260预测。

生成环境没有MATLAB/Octave，也没有机型Excel，未执行MATLAB实机测试。对应数学公式已经用Python独立核对；具体误差记录在验证记录.txt。需在MATLAB先运行上述验证脚本，再使用真实机型数据。

仍沿用准定常二维截面模型、直线刚性叶片和固定参考工况。未加入平均气动力/静平衡、气动刚度、翼型自身Cm、非定常失速、塔筒涡激载荷。不能将当前扰动力响应解释成完整塔筒VIV预测。
